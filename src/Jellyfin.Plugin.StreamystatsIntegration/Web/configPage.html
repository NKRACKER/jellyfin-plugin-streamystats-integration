Streamystats Integration

Geführte Einrichtung für Jellyfin 12. Das Plugin speichert keine Jellyfin- oder Streamystats-Zugangsdaten.

Vorbereitung und Installation
  1. Jellyfin Server und Jellyfin Web müssen zur Hauptversion 12 gehören.
  2. Streamystats muss bereits funktionieren und per HTTPS erreichbar sein.
  3. Empfohlen sind zwei Hosts derselben Site: media.example.com und stats.media.example.com.
  4. Der Stats-Reverse-Proxy muss die unten erzeugten Frame- und Session-Reset-Regeln erhalten.
  5. Danach Einstellungen speichern, Verbindung prüfen und Jellyfin Web vollständig neu laden.

Native TV-Clients wie Android TV und Swiftfin laden diese Web-Erweiterung nicht. Dort die konfigurierte Browser-URL verwenden.

Installation und Updates über den Jellyfin-Katalog
  1. Der Serverbetreiber fügt einmalig unter Dashboard → Plugins → Repositories die vom Herausgeber genannte manifest.json-URL hinzu.
  2. Danach wird das Plugin unter Dashboard → Plugins → Katalog installiert.
  3. Nach jeder Installation oder Aktualisierung muss der Jellyfin-Server vollständig neu gestartet werden.
  4. Updates erscheinen anschließend im normalen Jellyfin-Plugin-Katalog; Änderungen an index.html oder kompilierten Webdateien sind nie erforderlich.

Wenn das Plugin bereits hier angezeigt wird, ist die Installation abgeschlossen. Diese Seite dient jetzt nur noch der sicheren Streamystats-Einrichtung.

Streamystats festlegen

Standard: „Statistiken“.
HTTPS-URL, die alle Browser erreichen. Keine Zugangsdaten, Queryparameter oder Fragmente.
Erweiterter Healthcheck
Optional; nur Jellyfin ruft diese URL ohne Cookies oder Redirects ab. Leer verwendet die öffentliche URL.

          Fehlerdiagnose
          
    
            
  • „refused to connect“: Am Stats-Host ist noch X-Frame-Options: DENY vorhanden oder frame-ancestors nennt nicht diese Jellyfin-Origin.

  • Fehler direkt beim Öffnen: POST /__jellyfin_integration_reset muss 204, X-SSI-Session-Reset: 1 und die exakte CORS-Origin liefern.
    •

    •
